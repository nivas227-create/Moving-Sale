Bhaskar's Moving Sale Website

Files included
- index.html
- styles.css
- script.js
- items.js
- photos/ folder

How to edit later
The website reads from items.js.

You can edit:
- name
- category
- price
- status
- notes
- photo1/photo2/photo3
- room/location

How to add photos
1. Put images into the photos folder
2. In items.js, set photo1/photo2/photo3 to paths like:
   photos/my_item.jpg

How to mark an item sold
Change:
- Available
to:
- Pending
or:
- Sold

Best contact email on the site
movingssale2026@gmail.com

How to host
Upload all files to GitHub Pages, Netlify, Vercel, or any standard web host.
Make sure index.html stays in the main folder.
